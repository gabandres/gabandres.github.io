# Agenda — Privacy Policy

The published policy for the **Agenda** iOS app.

📄 **<https://gabandres.github.io/agenda-privacy/>**

Agenda is an offline-first app for keeping a private record of return visits and bible studies.
Everything entered stays on the device, encrypted with SQLCipher behind a passphrase-derived key
held in the iOS Keychain. There are no accounts, no cloud storage and no analytics.

The one network connection the app makes is a check for over-the-air code updates, which carries
no user data. The policy describes this in full.

This repository is public only because the App Store requires a publicly reachable privacy policy
URL. The app's source is not here.
